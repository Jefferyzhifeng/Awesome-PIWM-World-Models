# Contributing

Thank you for helping improve this Awesome list.

## Contribution Rules

- Ensure links are relevant to PIWM or World Models.
- Prefer primary sources (paper, official docs, official repo).
- Provide a one-line description for each new entry.
- Place entries in the correct category.
- Keep descriptions neutral and factual.
- Add tags when possible: `Paper`, `Code`, `Data`, `Survey`.

## PR Checklist

- No dead links.
- No duplicate entries.
- No purely promotional links.
- One-line summary is clear and specific.
- Category placement is correct.

## Entry Templates

Use one of the following:

- `**[Paper]** [Title](URL) - Main contribution in one line.`
- `**[Code]** [Project](URL) - What practitioners can run.`
- `**[Data]** [Dataset](URL) - Modality and benchmark role.`
- `**[Survey]** [Title](URL) - Scope and why it matters.`

## Pull Request Message Template

```text
### Summary
- Added: <resource name>
- Type: <Paper/Code/Data/Survey>
- Section: <list file name>
- Why useful: <one sentence>

### Checks
- [ ] Link opens
- [ ] No duplicates found
- [ ] Description is concise and neutral
```
