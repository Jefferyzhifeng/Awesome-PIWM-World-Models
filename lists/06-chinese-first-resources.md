## Bilingual Core References

- [PINNs (Raissi et al., 2019)](https://doi.org/10.1016/j.jcp.2018.10.045) - Core paper frequently interpreted in Chinese technical blogs.
- [Physics-Informed Machine Learning (Karniadakis et al., 2021)](https://doi.org/10.1038/s42254-021-00314-5) - Canonical review with broad Chinese secondary commentary.
- [DreamerV3 (Hafner et al., 2023)](https://arxiv.org/abs/2301.04104) - Strong world-model baseline for bilingual reading groups.
- [Medical World Model (Yang et al., 2025)](https://arxiv.org/abs/2507.01484) - A direct PIWM-relevant medical world-model exemplar.
- [MedSAM (Ma et al., 2024)](https://www.nature.com/articles/s41467-024-44824-z) - Widely discussed bilingual benchmark for promptable segmentation.
- [BiomedCLIP (Zhang et al., 2023)](https://arxiv.org/abs/2303.00915) - Strong image-text biomedical representation baseline.

## Suggested Reading Order (Chinese-First)

1. Start with PINN overview resources and one core paper.
2. Read diffusion and world-model fundamentals.
3. Move to medical world model and MedSAM/biomedical FM papers.
4. Compare against PIWM surveys and roadmap references.
