# Foundations and Milestones

> Canonical foundations and milestone works used in the PIWM survey.

Tag legend: `Paper` = research paper/report, `Survey` = review, `Code` = implementation/tooling, `Data` = benchmark/dataset.

## World Models and Predictive Learning

- **[Paper]** [Recurrent World Models Facilitate Policy Evolution (Ha & Schmidhuber, NeurIPS 2018)](https://papers.nips.cc/paper_files/paper/2018/hash/2de5d16682c3c35007e4e92982f1a2ba-Abstract.html) - A seminal latent dynamics world-model framework.
- **[Paper]** [A Path Towards Autonomous Machine Intelligence (LeCun, 2022)](https://openreview.net/forum?id=BZ5a1r-kVsf) - JEPA program framing predictive representation learning.
- **[Paper]** [Mastering Diverse Domains Through World Models / DreamerV3 (Hafner et al., 2023)](https://arxiv.org/abs/2301.04104) - A scalable model-based agent showing robust cross-domain transfer.
- **[Paper]** [Genie: Generative Interactive Environments (Bruce et al., ICML 2024)](https://arxiv.org/abs/2402.15391) - Interactive world generation from visual/text prompts.
- **[Paper]** [Video Generation Models as World Simulators / Sora (OpenAI, 2024)](https://openai.com/research/video-generation-models-as-world-simulators) - Large-scale generative world simulation perspective.

## Physics-Informed Learning

- **[Paper]** [Physics-Informed Neural Networks (Raissi et al., JCP 2019)](https://doi.org/10.1016/j.jcp.2018.10.045) - Core PINN formulation for forward and inverse PDE problems.
- **[Survey]** [Physics-Informed Machine Learning (Karniadakis et al., Nat Rev Phys 2021)](https://doi.org/10.1038/s42254-021-00314-5) - A broad map of physics-informed ML principles.
- **[Paper]** [Fourier Neural Operator (Li et al., ICLR 2021)](https://arxiv.org/abs/2010.08895) - Operator learning for parametric PDE families.
- **[Paper]** [DeepONet (Lu et al., Nat Mach Intell 2021)](https://doi.org/10.1038/s42256-021-00302-5) - Universal operator approximation with neural networks.
- **[Paper]** [Poseidon: Efficient Foundation Models for PDEs (Herde et al., 2024)](https://arxiv.org/abs/2405.19101) - PDE-oriented foundation-model scaling direction.
- **[Paper]** [Geometry-Informed Neural Operator (Li et al., NeurIPS 2023)](https://proceedings.neurips.cc/paper_files/paper/2023/hash/26fbe97265f8164f8e8cb2f97090c8d0-Abstract-Conference.html) - Large-scale 3D PDE operator learning with geometric priors.

## Generative Modeling Foundations

- **[Paper]** [Denoising Diffusion Probabilistic Models (Ho et al., NeurIPS 2020)](https://arxiv.org/abs/2006.11239) - Diffusion training objective used in many medical PIWM systems.
- **[Paper]** [Score-Based Generative Modeling Through SDEs (Song et al., ICLR 2021)](https://arxiv.org/abs/2011.13456) - Continuous-time generative framework for inverse problems.
- **[Paper]** [Solving Inverse Problems with Score-Based Models (Song et al., ICLR 2022)](https://openreview.net/forum?id=vaRCHVj0uGI) - Foundational sampling framework for reconstruction.

## Medical Imaging AI Foundations

- **[Survey]** [A Survey on Deep Learning in Medical Image Analysis (Litjens et al., 2017)](https://doi.org/10.1016/j.media.2017.07.005) - Early comprehensive map of medical imaging deep learning.
- **[Survey]** [Deep Learning in Medical Image Analysis (Shen et al., 2017)](https://doi.org/10.1146/annurev-bioeng-071516-044442) - Core review connecting algorithms and clinical tasks.
- **[Paper]** [nnU-Net (Isensee et al., Nat Methods 2021)](https://doi.org/10.1038/s41592-020-01008-z) - Strong practical baseline for segmentation workflows.
- **[Paper]** [Towards a General-Purpose Foundation Model for Computational Pathology (Chen et al., 2024)](https://doi.org/10.1038/s41591-024-02857-3) - Pathology foundation-model milestone.
- **[Paper]** [A Visual-Language Foundation Model for Computational Pathology (Lu et al., 2024)](https://doi.org/10.1038/s41591-024-02856-4) - Large-scale multimodal pathology representation learning.
