# Awesome PIWM & World Models [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

![Overview](overview.png)

A curated, research-and-engineering-focused list for **Predictive/Physics-Informed World Models (PIWM)** and broader **World Models**, populated from the literature base in the companion survey project.

This repository prioritizes:
- PIWM as the main thread
- broader World Model coverage for context
- high-signal resources with practical engineering value

## Curation Status

- Scope: PIWM + World Models for medical imaging (research and engineering)
- Structure: 8 thematic lists
- Entry style: one-line summary + category tags when applicable
- Primary source policy: paper/official docs/official repo first

## Getting Started Paths

### Path A: Researcher (Concepts First)
1. Read milestones in `lists/01-foundations.md`
2. Study evaluations in `lists/04-benchmarks-and-evaluation.md`
3. Compare methods in `lists/02-piwm-methods.md`

### Path B: Builder (Code First)
1. Start from `lists/05-open-source-and-toolkits.md`
2. Select environments from `lists/03-datasets-and-environments.md`
3. Track implementation checklists in `lists/08-reproducibility-and-engineering.md`

### Path C: Balanced (Research + Engineering)
1. Read `lists/07-surveys-and-roadmaps.md`
2. Pick one method from `lists/02-piwm-methods.md`
3. Reproduce with resources from `lists/05-open-source-and-toolkits.md`
